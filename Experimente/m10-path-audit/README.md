Die Auswertung enthält 5.120 Gewichtsvergleiche, 1.280 A-/D-Vergleiche und 320
Gewichtsvergleiche zwischen Belegungen. Die neuen Replaymessungen umfassen
7.680 Phasentraces mit 275.520 Ereignissen. Die ursprünglichen M9-Ergebnisse und
sechs CSV-Begleitdateien werden unverändert reproduziert.

Im gekoppelten Kombinationsarm wirken Core-Gewichtsänderungen in 160/160
Proben auf Eingangsimpulse und synchrone Potenziale, in 61/160 auf das
Spikezählmuster und in 5/160 auf die feste Klassenentscheidung. Das ist eine
mechanistische Diagnose, kein funktionaler Lernnachweis.
